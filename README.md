# CasA_Echoes
Fitting peaks of infrared echoes of Cassiopeia A found with JWST. Conceptually, we are seeking an upper limit to the shock breakout duration of Cas A that powered these infrared echoes. Contains python scripts to extract flux profiles and fitting toy model light curves convolved with a Gaussian to fit the data. The toy model is an asymmetric curve where we can choose different rise and fall times (the shock breakout) and the Gaussian represents the impact of dust width and PSF (the broadening by the dust).
